# **Metodología**

Se propone utilizar una metodología iterativa e incremental, organizada en etapas de análisis, diseño, desarrollo, pruebas y despliegue. Este enfoque permite construir el sistema progresivamente, validar las funcionalidades implementadas y realizar ajustes durante el desarrollo.

## ***Etapas de trabajo***

1. **Análisis de requisitos:** relevar y documentar las necesidades del Colegio, definir objetivos, alcance, actores, casos de uso y requisitos funcionales y no funcionales.  
2. **Diseño del sistema:** definir la arquitectura, el modelo de datos, los diagramas y los mockups de las interfaces.  
3. **Preparación del entorno:** configurar Django, PostgreSQL mediante Supabase, el almacenamiento de archivos y el repositorio Git.  
4. **Desarrollo incremental:** implementar la autenticación y los permisos; luego, el directorio público, el panel del matriculado, la gestión de contenidos y las funciones administrativas.  
5. **Pruebas y correcciones:** verificar el funcionamiento de las funcionalidades, los permisos, la privacidad de los datos y la adaptación de las interfaces a distintos dispositivos.  
6. **Despliegue y documentación:** publicar la aplicación en el entorno seleccionado, comprobar su funcionamiento en línea y documentar la solución desarrollada.

La metodología contempla revisiones durante todo el proceso. Las etapas podrán ajustarse según las observaciones del docente, la aprobación del Colegio y las dificultades técnicas que se presenten.
