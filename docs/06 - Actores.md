# **Actores**

| *Actor* | *Descripción* | *Responsabilidades principales* |
| :---- | :---- | :---- |
| **Público** | Persona que accede al sitio sin iniciar sesión. | Consultar información institucional, noticias, eventos y directorio de matriculados. |
| **Matriculado** | Profesional registrado en el Colegio que posee una cuenta de acceso. | Consultar sus datos personales y profesionales, modificar sus datos de contacto y configurar su visibilidad pública. |
| **Colaborador** | Usuario autorizado para gestionar contenidos institucionales. | Crear, editar y publicar noticias, novedades y eventos. No puede administrar matriculados, usuarios ni permisos. |
| **Administrador** | Usuario con permisos de administración del sistema. | Gestionar matriculados, especialidades, cuentas, roles, contenidos y documentos institucionales. |
